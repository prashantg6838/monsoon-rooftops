# Unity workflow: numbered steps

Tell Claude "run step N" and it will know which of these you mean.

## Steps you repeat

1. **Stop the game before changing code.** If Play is on, click Stop first. Editing scripts during Play causes camera errors.
2. **Wait for recompile.** After Claude changes files, click into the Unity window. Wait for the spinner at the bottom right to finish. If the Console shows red errors, copy the first one to Claude.
3. **Run the EditMode tests.**
   1. Menu: **Window > General > Test Runner**.
   2. Click the **EditMode** tab at the top left of that window.
   3. Click **Run All**.
   4. Green ticks mean pass. A red cross means fail: click it and copy the message at the bottom to Claude.
   - Expected count right now: **56** EditMode tests (12 levels are each checked twice).
4. **Run the PlayMode test.** Same window, click the **PlayMode** tab, then **Run All**. Expected: **1** test.
5. **Clear the Console.** Console tab, click **Clear**, so old messages don't confuse you.
6. **Try the game in the editor.**
   1. Open the scene: **Assets/_Project/Scenes/Greybox**.
   2. Click the **Play** button at the top centre. Use the **Game** tab.
   3. The game opens on the **level map**. Click a level tile. Inside a level, **Map** (top left) goes back.
   4. Controls: click a tray part, then click a cell (or drag it). Click a placed part to rotate it. Q and E (or the View buttons) turn the camera. Mouse wheel zooms. Drag empty space to pan.
   5. Click **Stop** when done (see step 1).
7. **Build and run on the Motorola.**
   1. Phone: plug in by USB, unlock it, accept "Allow USB debugging" if asked.
   2. **File > Build Profiles > Android**. Make sure the Greybox scene is ticked in the Scene List.
   3. Click **Refresh** next to Run Device and choose the Motorola.
   4. Click **Build And Run**. Save the APK in a `Builds` folder outside the project.
   5. The first build takes 5 to 15 minutes. Later builds are faster.

## One-time steps (already done, only redo if something breaks)

8. **Apply Android settings:** menu **Monsoon > Apply Android Settings**.
9. **Create the Greybox scene:** menu **Monsoon > Create Greybox Scene**. This overwrites the scene, so only run it if the scene is missing or broken.
10. **Input handling:** **Edit > Project Settings > Player > Other Settings > Active Input Handling**. Set it to **Input System Package (New)**. Unity restarts.

11. **Reset saved progress:** menu **Monsoon > Reset Saved Progress**. Locks levels 2-12 again and replays tutorials.
12. **Level editor:** menu **Monsoon > Level Editor**. Load a level by id, paint cells, set parts/waves/goals, Save.
    Levels 1-12 are generated by `python3 -I tools/make_levels.py`, which also balances the star goals.
    Running that script overwrites hand edits to those 12 files.
