# Monsoon Rooftops

Unity 6 LTS (URP) landscape puzzle game for Android. Master plan: [docs/monsoon-rooftops-dev-plan.md](docs/monsoon-rooftops-dev-plan.md).

## Phase 0 setup
1. Install Unity Hub, then Unity 6 LTS with Android Build Support (OpenJDK, SDK & NDK Tools).
2. In Unity Hub: Add > Add project from disk > select this folder.
3. Let it import. If asked about the Input System backend, choose Yes and restart.
4. Menu: Monsoon > Apply Android Settings.
5. Window > General > Test Runner > EditMode > Run All (3 tests should pass).
6. Phone: enable Developer options and USB debugging, connect, File > Build Profiles > Android > Build And Run.
